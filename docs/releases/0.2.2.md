# Release 0.2.2 — plan & status

Model rewriting + option / robustness fixes, plus auto-naming polish and
RuleMap token-bearing wrapper fidelity ([#33](https://github.com/miho/VMF-Text/pull/33)
folded in so this is a **single** Maven Central publish — no separate 0.2.3),
plus the Maven Central plugin-marker fix and the Gradle 10 build cleanup
(2026-10-20).
Process: [`docs/RELEASING.md`](../RELEASING.md). Full notes:
[`CHANGELOG.md`](../../CHANGELOG.md) (`## [0.2.2]`). Tracking issue:
[#29](https://github.com/miho/VMF-Text/issues/29).

- **Version:** `0.2.2` (`config/common.properties`); VMF stays `0.2.10`,
  ANTLR `4.13.2`.
- **Release commit:** tip of `main` (includes #33 and the plugin-marker /
  build-hygiene PR). The annotated tag `v0.2.2` is moved to it whenever the
  release commit changes (moved 2026-09-17 for #33, and again 2026-10-20).
- **Headline:** parser rule maps / model rewriting (`RuleMap`,
  [#1](https://github.com/miho/VMF-Text/issues/1)); fail-fast code generation +
  tinylog logging; `superClass` option fix
  ([#14](https://github.com/miho/VMF-Text/issues/14)); aarch64 miniclang test
  guard ([#23](https://github.com/miho/VMF-Text/issues/23)); Gradle-plugin
  JDK 17 load fix; automatic naming polish (#31); RuleMap token-bearing shells
  (#32); plugin marker published to Maven Central again (0.2.1 had none);
  Gradle 9.8.2 + Gradle 10-clean builds.
