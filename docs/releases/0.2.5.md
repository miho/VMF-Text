# Release 0.2.5 — plan & status

GitHub release only (see `docs/RELEASING.md` §3b): the organization's monthly
Maven Central release budget is shared with other `eu.mihosoft` projects, and
this batch is available to early adopters as `0.2.5-SNAPSHOT` on the Central
snapshot repository anyway. Notes: `CHANGELOG.md` `[0.2.5]`.

- **Version:** `0.2.5` (`config/common.properties`); VMF `0.2.11`, ANTLR `4.13.2`.
- **Scope:** Python 3 support end to end — #51 (predicate-free check rules,
  #48), #55 (Python trial: five core fixes #52/#53/#54, `tokens {}` block,
  identity equals), #56 (`reindent(...)`), #57 (naming #47), #58 (split
  grammars #39), #59 (trial on the grammars-v4 files as they are), #66
  (indentation tokens for blocks built from scratch and optional punctuation
  of programmatic elements, #60), #67 (camelCase classes for snake_case
  rules and lifted names without stacked suffixes #63, one parser base class
  #62). Regression grammars added: `optblock`, `labeledopt`, `itemlift`,
  `naming`, `splitlex`, `indent`.
