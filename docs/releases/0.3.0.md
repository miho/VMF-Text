# Release 0.3.0

Generated models use containment [#81](https://github.com/miho/VMF-Text/pull/81),
with parent links managed by VMF, structural equality, and subtree
traversal. The release also improves round trips for skipped trivia and
repeated literals, and updates automatic labels. Dependencies are VMF 0.4.0
and ANTLR 4.13.2. See the [changelog](../../CHANGELOG.md).
